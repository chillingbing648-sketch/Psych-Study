# 🧠 PsychStudy AI

A smart **Psychology Study Companion** designed to help students prepare for exams more efficiently.

PsychStudy AI helps students convert notes, question banks, and PDFs into **structured study material, quizzes, and revision tools**.

---

## ✨ Features

- 📄 Upload PDFs or notes
- 🧠 Generate psychology topics automatically
- ❓ Create quiz questions for practice
- 📝 Generate exam-style papers
- 📚 Study flashcards
- 📊 Interactive learning dashboard
- 🌙 Light / Dark theme support

---

## 🎓 Designed For

Psychology students preparing for:

- University Exams
- Internal Assessments
- Competitive Exams
- Quick Revision

Especially useful for **Indian education exam patterns**.
